# Reviews

Dated review lanes, each a directory of finder reports and the reverify evidence
that closed or rejected them. They are kept because the measurements behind a
rejection live here, and re-deriving one costs more than reading it.

Nothing here is an instruction. A lane records what was true on its date: the
`just` recipes, `VCOWS_GATES` names and file paths it cites may be gone, and the
code it quotes has moved on.

`docs/findings.md` is where a rejection becomes a rule. If a lane and
`docs/findings.md` disagree, `docs/findings.md` wins.
